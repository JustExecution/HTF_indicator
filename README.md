# HTF SUITE

A professional **TradingView Pine Script v6** indicator that combines Higher Timeframe (HTF) market structure, fractal models, CISD, SMT Divergence, session analysis, and projection tools into one unified trading framework.

Designed for traders who rely on **multi-timeframe analysis** and ICT/Smart Money concepts, HTF SUITE provides institutional market context without requiring multiple indicators.

## Features

### Multi-Timeframe HTF Candles

* Display live Higher Timeframe (HTF1) candles directly on your chart.
* Display an additional Higher Timeframe (HTF2) for broader market context.
* Adjustable candle size, colors, spacing, offsets, and styling.
* Optional:

  * HTF Open levels
  * Open/Close timing lines
  * High/Low projection lines

---

### Intelligent Fractal Mapping

Automatically maps chart timeframes to logical higher timeframes.

Supports five operating modes:

* **Automatic**
* **Intraday**
* **Scalp**
* **Swing**
* **Custom**

Custom mode allows complete manual selection of LTF, HTF1, and HTF2.

---

### Fractal Model Detection

Visualizes complete market fractal sequences including:

* Candle 1 Liquidity Sweep
* Candle 2
* Candle 3
* Candle 4

Optional confirmation filters include:

* CISD confirmation
* Bullish/Bearish Bias
* Valid / Failed model detection

---

### CISD Engine

Built-in Change in State of Delivery (CISD) detection.

Features include:

* Bullish CISD
* Bearish CISD
* Historical CISD tracking
* Optional CISD requirement for model validation
* Adjustable line styles and extensions

---

### Order Block Projection Tool

Automatically projects future Order Block levels.

Features:

* Custom projection levels
* Projection labels
* Adjustable colors
* Custom line styles
* Projection extensions

---

### Fair Value Gap (First Presented FVG)

Detects and highlights the first Fair Value Gap within qualifying market structures.

Optional:

* Labels
* Custom fill colors
* Border colors
* Transparency controls

---

### Market Structure Visualization

Includes visual tools such as:

* Candle equilibrium levels
* T-Spot highlighting
* Liquidity sweep visualization
* Market model labels

Fully customizable styling.

---

### SMT Divergence

Integrated SMT (Smart Money Technique) divergence engine.

Supports:

* Automatic comparison symbols
* Manual symbol selection
* Second comparison symbol
* Swing detection
* SMT merging
* Invalidation logic
* Custom labels and line styling

---

### Session Tools

Visualize important trading sessions including:

* Asia
* London
* New York

Supports:

* Box mode
* Line mode
* Session labels
* Session history
* Current-day-only mode

Also includes:

* True Day Open (TDO)
* Previous Day Open levels
* Adjustable session colors

---

### Time Filters

Restrict indicator calculations to specific trading sessions.

Configure up to three independent session filters.

Useful for:

* Killzones
* Trading windows
* Custom session-based strategies

---

### Information Table

Displays real-time market information including active fractal context.

Customizable:

* Position
* Text size
* Colors
* Background

---

### Highly Customizable

Almost every component can be enabled, disabled, or customized:

* Colors
* Transparency
* Labels
* Line styles
* Widths
* Candle size
* Session behavior
* Projection levels
* HTF visualization
